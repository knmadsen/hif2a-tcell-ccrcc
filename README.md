# hif2a-tcell-ccrcc
Analysis code for "Pharmacologic HIF-2α inhibition preserves T cell effector function in clear cell renal cell carcinoma." Includes scripts for RNA-seq analysis in the manuscript.

## Overview

RNA-seq data were processed using the following workflow:

1. Reference preparation
2. STAR alignment
3. RSEM quantification
4. Downstream analysis and visualization in R

## Software and Reference

RNA-seq alignment and quantification were performed using the
`gtex_rnaseq_V11.sif` Apptainer container.

The container was obtained from the official GTEx Docker image (https://hub.docker.com/r/broadinstitute/gtex_rnaseq).

The reference genome used for the analysis was:

- Genome: GRCh38.p10
- NCBI accession: GCA_000001405.25
- Gene annotation: GENCODE annotation 

The analyses were performed on the Yale Bouchet HPC cluster using Apptainer.

## Reference Index Preparation

STAR and RSEM reference indices were generated from the GRCh38 reference genome
and the corresponding GENCODE annotation.

The STAR genome index was generated using a splice junction overhang of 90 bp.

```bash
apptainer exec --bind ./:/data gtex_rnaseq_V11.sif bash -c "STAR \
    --runMode genomeGenerate \
    --genomeDir /data/references/star_index_oh90 \
    --genomeFastaFiles /data/references/genome.fa \
    --sjdbGTFfile /data/references/GRCh38.gencode.collapsed.gtf \
    --sjdbOverhang 90 \
    --runThreadN 8"
    
apptainer exec --bind ./:/data gtex_rnaseq_V11.sif bash -c " \
    rsem-prepare-reference \
    /data/references/genome.fa \
    /data/references/rsem_reference \
    --gtf /data/references/GRCh38.gencode.collapsed.gtf \
    --num-threads 8"
```

### STAR alignment

STAR alignment was performed using the `run_STAR.py` script included in the container.

```bash
SAMPLE=$(sed -n "${SLURM_ARRAY_TASK_ID}p" sample20260630.txt)

apptainer exec --bind ./:/data gtex_rnaseq_V11.sif bash -c "
  /src/run_STAR.py \
    /data/references/star_index_oh90 \
    /data/fastq/${SAMPLE}.fastq.gz \
    ${SAMPLE} \
    --threads 8 \
    --output_dir /data/star_out
"
```

### RSEM

Gene-level quantification was performed using RSEM from the transcriptome-aligned BAM files generated by STAR.
```bash
SAMPLE=$(sed -n "${SLURM_ARRAY_TASK_ID}p" sample20260630.txt)

apptainer exec --bind ./:/data gtex_rnaseq_V11.sif bash -c "
  /src/run_RSEM.py \
    /data/references \
    /data/star_out/${SAMPLE}.Aligned.toTranscriptome.out.bam \
    /data/${SAMPLE} \
    --paired_end false \
    --threads 8
"
```

### Downstream analysis

Downstream RNA-seq analyses were performed in R.

Gene-level RSEM expression estimates were used as the primary input for downstream analyses.  
Raw expression values were processed and normalized as appropriate for each analysis.  
The specific R scripts used for each analysis are provided in the corresponding directories of this repository.
